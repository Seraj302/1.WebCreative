# WebCreative

Hemsida för WebCreative – modern webbdesign för små företag och startups.

Hela sidan ligger i en enda fil, `index.html` (HTML, CSS och JavaScript i samma fil).

## Innehåll
- Fyra prispaket: Basis (5 000 kr), Startup (9 000 kr), Professional (13 000 kr) och Enterprise (22 000 kr)
- Beställningsformulär och varukorg
- Tjänster, process, portfolio, omdömen och FAQ

## Köra lokalt
Öppna `index.html` i valfri webbläsare. Inget bygge eller server behövs.

## Publicera gratis med GitHub Pages
Settings → Pages → Branch: `main` / root → Save.
